# AgentSwarm Procedure

Last Material Revision: 2026-08-01

## What AgentSwarm Is

AgentSwarm is the research and project-execution method used in this project. AgentSwarm is NOT the project. AgentSwarm is NOT the standard. AgentSwarm is NOT the legal subject.

## Per-Agent Requirements

Every agent must receive:

- Unique research-agent ID
- Parent-task ID
- Role
- Bounded mandate
- Source permissions
- Tool permissions
- Required outputs
- Evidence requirements
- Prohibited actions
- Escalation conditions
- Validation agent
- Completion criteria

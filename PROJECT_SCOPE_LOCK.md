# Project Scope Lock

The scope defined in `PROJECT_CHARTER.md` is locked. Any change requires written authorization from Pierre-Edward Procyk.

## Prohibited Scope Reductions

The following may NOT be silently removed, weakened, or replaced with shorter substitutes: universal AI agent coverage; permanent identifier requirements; append-only, tamper-evident, sequence-aware, cryptographically linked event history; public/semi-public/private/offline registry tiers; quality-evidence requirement; Canadian jurisdiction analysis; AegisTrace functional implementation; arXiv LaTeX project; government proposal package; university research package; independent validation; final archive with checksums.

## Prohibited Scope Expansions

The following may NOT be added without authorization: external publication; external deployment; public licence application; new logo generation; new brand identity; new partnerships, endorsements, or sponsorships; new business registration data; new academic or government affiliations; new co-authors; new project sponsors.

## Enforcement

The A01 Project Authority Guardian agent role is responsible for enforcing this scope lock. Violations are recorded in `project-control/RISK_REGISTER.md` and `project-control/BLOCKER_REGISTER.md`.

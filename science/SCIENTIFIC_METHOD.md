# Scientific Method

Last Material Revision: 2026-08-01

## Hypotheses

H1: The framework's 23 invariants all hold under test.

H2: The reference implementation passes all 113 security, privacy, permanence, and conformance tests.

H3: The framework's privacy safeguards prevent the framework from becoming a surveillance system, provided that pseudonymous identifiers, sealed identity resolution, content separation, access logging, and recourse are enforced.

H4: The framework's tiered conformance levels accommodate small developers and open-source projects alongside enterprise and regulated-sector deployments.

H5: The framework's cost-benefit balance is positive for most Canadian organizations over a five-to-ten-year horizon.

## Variables

- Independent variable: AI-IDP implementation (with vs without privacy safeguards; with vs without tiered conformance).
- Dependent variables: invariant adherence (binary); test pass rate (count); privacy properties (binary); conformance-level achievement (categorical); cost-benefit NPV (continuous).
- Control variables: Python 3.12; Ed25519; SHA-256; SQLite; deterministic test execution.

## Experimental Design

The experimental design combines: (1) unit tests for each module; (2) integration tests for complete workflows; (3) security tests for attack scenarios; (4) privacy tests for privacy properties; (5) permanence tests for permanence properties; (6) conformance tests for invariant adherence; (7) benchmarks for performance characteristics.

## Benchmark Design

- Event recording throughput (events per second).
- Ledger verification throughput (events per second).
- Merkle root computation time (ms).
- Memory usage (MB).
- Storage usage (MB).
- Latency per operation (ms).

All benchmarks use synthetic data, clearly labelled as synthetic, generated by reproducible scripts with fixed random seeds.

## Statistical Analysis Plan

- Descriptive statistics: mean, median, standard deviation, min, max.
- Confidence intervals: 95% confidence intervals for benchmark means.
- Uncertainty analysis: parametric models for cost-benefit analysis with sensitivity analysis.

## Reproducibility Procedures

- All dependencies pinned in pyproject.toml.
- All tests deterministic (Ed25519 signatures are deterministic; no random seeds).
- The demo scenario produces a verifiable ledger from scratch.
- All synthetic benchmark data generated by reproducible scripts with fixed random seeds.
- A clean rerun of the test suite produces the same results.

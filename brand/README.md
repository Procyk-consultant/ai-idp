# Brand assets

This directory contains the official identity assets used by the AI-IDP/AegisTrace repository.

## Cognitive Industries originals

The files in `originals/` are the checksum-locked Cognitive Industries originals:

- 3D hexagonal identity mark;
- bilingual horizontal Cognitive Industries — Les Industries Cognitives lockup;
- brand-guidelines reference card.

Their controlling checksums are recorded in `originals/SHA256SUMS.txt`.

## AI-IDP and AegisTrace project marks

The files in `project-marks/` are byte-for-byte copies of the official project assets selected from the rights holder’s local archive:

| Mark | Purpose |
|---|---|
| `ai-idp-official-logo-full.png` | Full AI-IDP identity and delegation lockup |
| `ai-idp-logo-icon.png` | AI-IDP standalone icon |
| `aegistrace-official-logo-full.png` | Full AegisTrace accountability-engine lockup |
| `aegistrace-logo-icon.png` | AegisTrace standalone icon |
| `ai-idp-aegistrace-brand-colours.png` | Project colour-system reference |
| `ai-idp-aegistrace-typography.png` | Typography reference |

Their controlling checksums are recorded in `project-marks/SHA256SUMS.txt` and in the public [media manifest](../docs/media/MEDIA_MANIFEST.md).

# Reproducibility Statement

Last Material Revision: 2026-08-01

The AegisTrace reference implementation is reproducible.

## Determinism

- All tests are deterministic. Ed25519 signatures are deterministic (RFC 8032). No random seeds are used in tests.
- The demo scenario (`aegistrace admin demo`) produces a verifiable ledger from scratch. The ledger's event hashes and signatures are deterministic.

## Pinned Dependencies

All Python dependencies are pinned in `pyproject.toml`. The reference implementation requires Python 3.12 or later. The dependencies are: `cryptography` (Ed25519, hashing), `pydantic` (data models), `fastapi` (API server), `jsonschema` (schema validation), `pytest` (test framework).

## Clean Rerun

A clean rerun of the test suite produces the same results. To verify:

```powershell
Set-Location -LiteralPath 'C:\Cognitive Industries\AI-IDP-AegisTrace'
.\.venv\Scripts\python.exe -m pytest tests\ -v
```

The expected result is 113 passed, 0 failed.

## Synthetic Data

All synthetic benchmark data is generated by reproducible scripts with fixed random seeds. Synthetic data is clearly labelled as synthetic. Real deployment data is not available; this is documented as a limitation.

## Reproducibility Package

The reproducibility package is in `science/reproducibility/`. It includes:

- `ENVIRONMENT.md` — the execution environment
- `STEPS.md` — step-by-step reproduction instructions
- `EXPECTED_RESULTS.md` — expected test and benchmark results
- `CHECKSUMS.sha256` — checksums of the reproducibility package files

## Limitations

The reproducibility statement applies to the reference implementation and the test suite. Production deployments may produce different results due to different hardware, network conditions, and workloads. The reference implementation is designed for correctness and clarity, not maximum throughput.

# Contributing

## Status

This project is currently a single-author research and engineering effort by Pierre-Edward Procyk. **No public licence has been applied.** External contributions are NOT accepted until a licence is approved in writing by Pierre-Edward Procyk. If you have identified an error, security issue, or improvement, contact p.procyk.media@gmail.com.

## Code Standards

Python 3.12+. Strict static typing. Ruff lint. pytest tests. 100% type-check pass. All headers per `brand/DOCUMENT_IDENTITY_RULES.md`. No TODO, FIXME, pass-only critical functions, ellipsis bodies, fake responses, hardcoded success, fake cryptography, placeholder authentication/authorization, fabricated benchmarks/citations, or empty compliance/documentation files.

## Engineering Discipline

All code, schemas, scripts, infrastructure, documentation, and release artifacts follow the engineering discipline defined by `AGENTS.md`, `PROJECT_SCOPE_LOCK.md`, and `research/protocol/AGENTSWARM_PROCEDURE.md`.
